# AirSim Android Drone Control System

## 📱 Overview
This project is a capstone initiative developed at California State University San Marcos (CSUSM), sponsored by MCTSSA (Marine Corps Tactical Systems Support Activity). It implements a two-phone drone control system using Android, and Peer To Peer connections. One phone acts as the **User Controller** (manual and autopilot control), and the other as the **Drone Phone**, communicating with the physical drone controller.
